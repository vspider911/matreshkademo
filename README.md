# Matreshkademo — демо-сайт салона красоты «Матрёшка»

Демо-версия сайта салона красоты «Матрёшка» (Москва, Старопетровский проезд, 8, метро «Войковская»). Фиолетовый стиль.

Реальные: название, адрес и как добраться, часы работы 10:00–22:00, отзывы и имена мастеров из отзывов на Яндекс Картах, набор услуг, карта и кнопка «Маршрут».
Условные: телефон `+7 (000) 000-00-00`, цены, рейтинг, ссылки на мессенджеры.
Сверху полоса «Демо-версия сайта — телефон, цены и рейтинг условные».

## Что на сайте
- Первый экран с рейтингом, часами работы и статусом «Открыто / Закрыто» по московскому времени.
- 8 разделов услуг с ценой и длительностью каждой процедуры.
- Липкая сцена «Две услуги — одно время»: время визита не растёт, когда добавляются услуги.
- Цены для новых клиентов.
- Онлайн-запись: услуги по разделам, переключатель «Делать одновременно» с расчётом сэкономленного времени, день и время (занятые слоты зачёркнуты), имя и телефон. Заявка никуда не отправляется.
- Мастера и отзывы, атмосфера.
- Бьюти-коворкинг для мастеров — отдельным блоком, не в каталоге услуг для клиентов.
- Контакты и Яндекс Карта. На телефоне внизу закреплены «Позвонить» и «Записаться».

Фото — бесплатные снимки с Unsplash в формате WebP, лежат в `img/`.

## Как открыть
Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

и перейдите на http://localhost:8000
